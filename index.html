03 / MIS TEMAS

Añadir material

Importa un archivo TXT con apuntes o un JSON con notas y preguntas. Los TXT se pueden buscar y leer, pero no generan preguntas automáticamente. PDF y Word aún no se indexan: conviértelos a texto o comparte el material más adelante para prepararlo.

Formato JSON de preguntas

La respuesta es el índice de la opción correcta: 0, 1, 2 o 3. Cada pregunta necesita cuatro opciones distintas y una explicación.

{
  "title": "Mi tema",
  "notes": "Mis apuntes...",
  "questions": [{
    "prompt": "¿Pregunta?",
    "options": ["Correcta", "Opción B", "Opción C", "Opción D"],
    "answer": 0,
    "explanation": "Por qué es correcta.",
    "source": "Referencia para contrastar"
  }]
}

Tus materiales se guardan solo en este navegador; los resultados de práctica no se conservan al recargar. No subas datos sensibles. Exporta una copia: borrar los datos del navegador también elimina tus temas.
